    About these metrics

    Input and output tokens are from actual model calls. GPU energy is measured: average watts × busy seconds ÷ 3,600. Where a value is null or missing, you will see a dash or "Not measured".

    Multiply the token counts by your API rate, or the energy by your electricity cost, to find your own cost.

    Design notes

    • Style: data-dense dashboard. Fira Sans for text, Fira Code for every number.
    • One accent, deep blue. Green, red and amber appear only as data meaning.
    • Stat strips and rule lines replace card rows. Panels only where a block needs lifting.
    • Every page has Back and Home; the trail shows where you are.
    • All numbers here are sample values. Prices marked "to verify" are not confirmed.
