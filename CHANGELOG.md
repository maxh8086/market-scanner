# Changelog

All notable changes to this project are recorded here. Newest first.

## [Unreleased]

### Added
- `pyproject.toml` with project metadata and the pytest build gate (`testpaths = ["tests"]`). Run with `.venv\Scripts\python.exe -m pytest`.
- `CHANGELOG.md`.
- Shared glossary: design RFC at `docs/designs/shared-glossary.md`, ADR 0001 (`docs/adr/0001-shared-glossary-format.md`), JSON data file `config/glossary.json`, loader `scanner/glossary.py` with 20 unittest tests.
- Wireframe (`ui/wireframes/strategy.html`): Sector and industry performance chart on the stock page, Sector tab. It replaces the sector heat strip. Two tabs (Sector, Industry), windows 1D to 5Y, five top and five weakest groups by median return. Sample values only; the data source and the median rule are still to be designed.
- Wireframe: glossary entries `run`, `mo_perf` and `perf_members`.
- Wireframe: Order book tab on the stock page (`p-orders`): keyword filter with four LODR order groups, sample filings with a cancelled order, summary, last four quarters, and a table with the left-out filings. Glossary entries `ob_orders`, `ob_total`, `ob_filter` and `ob_lodr`.
- Wireframe, approved proposals built (2026-11-01): P1 sticky verdict header also on phones; P3 saved filters on the Stocks screen (browser storage only, up to 10); P4 exit count badge on the Holdings menu item; P5 sortable columns and a column chooser on the Stocks screen. P2 (compare two stocks) is deferred until after the first release.
- Wireframe: Actions pane on phones (640px and below). Ask AI, Size this position and Connect Broker move into a collapsed right-side "Actions" pane, opened from a handle on the right edge. It closes on Escape, an outside tap, Close or any action.
- Wireframe: Bucket column sort cycles A to Z, Z to A, verdict rank, then default (alphabetical).
- `docs/wireframe-review-2026-11-01.md`: full text of the five review-page sections removed from `#/review` on 2026-11-01.
- `scripts/ensure_postgres.ps1`: checks Docker is up, starts `scanner-postgres` (`docker compose up -d`, a no-op if running) and waits up to 60 seconds until it is healthy. `start.ps1` calls it before the databases stage.

### Decisions
- 2026-10-31, initial brief: Written by the brainstorm and Goldfish review (six lenses plus synthesizer). Covers one glossary file, one entry per column, formula checks, build warning, and the open questions.
- 2026-10-31, decisions recorded: Wording is generated by an LLM from the data and signed off by the user. Renames go in one commit with a grep test, with no alias layer. The build warns on a missing entry and the test suite fails on a formula mismatch or a Screener-name hit. The Screener-name check covers every output. Excel headers are display labels.
- 2026-10-31, open points resolved: Sign-off covers wording and labels, not the wireframe. Wording is conditional on the data present. Hidden backend-only columns get a short record entry and no tooltip. `above_sma200` and `above_ema50` stay in the backend. Stored runs are re-run through a key mapping.
- 2026-10-31, ADR 0001 accepted: format, gates and key-match check decided (see the ADR).
- 2026-10-31, build gate added: `pyproject.toml` sets the pytest gate (`testpaths = ["tests"]`).
- 2026-11-01, wireframe review: all 17 decisions and all 5 proposals on the `#/review` screen approved as recommended. Decisions: four verdicts; buy blocked on governance points 4, 5 and 18; 2% all-time high tolerance on closing basis; profit high within the data window; exit price proposal keeps the plan's rule with your own exit price overriding it; largest allocation 15% of Net Asset Value; Trim is information only; held 3 of 3 shows BUY; 200-day moving average (200 DMA); holdings outside the universe are tested and marked Not in universe; rank cut at the eligibility line; holdings input is upload first; funds and ETFs count for allocation and risk but are not scored; chart defaults and events as listed; glossary tooltips on the label text; interface built in Node.js with Tailwind and TradingView Lightweight Charts. Proposals: sticky verdict header, compare two stocks (after first release), saved filters, exit watch count in the navigation, sortable columns and column chooser.
- 2026-11-01, decision 10 reversed: the wireframe uses a simple 200-day moving average (200 DMA) and a 50-day exponential average (50 EMA). There is no 200 EMA anywhere. Glossary keys `ema200`, `cross50_200` and `exit_rule_ema` keep their names, but their text says 200 DMA. The technical vote list counts EMAs 10, 20, 50 and 100 only. Checked: the backend computes a simple 200-day average only.

### Changed
- `tests/test_import_sqlite.py`: the reachability probe (`SELECT 1`) moved to module level, and the class is skipped with `@unittest.skipUnless` when Postgres is unreachable. The unguarded `setUpClass` connect no longer errors, and the class counts as skipped. It is also skipped when `data/history.db` is missing, so the tests are no longer errors in a checkout without that file.
- `scanner/pg/db.py` `dsn()`: raises RuntimeError when `POSTGRES_DSN` user or database differs from `POSTGRES_USER` or `POSTGRES_DB` (names only, no password or host). Tests in `tests/test_pg_dsn.py`.
- `handoff.md`: ruflo cleanup closed. Decisions recorded under "Questions closed this session", item 8.
- Wireframe fixes (commits `64da241`, `05cbd3e`, `7b24ac9`): contrast, unique heading ids, info buttons outside labels, visible theme toggle text, no sideways page scroll, chart and stock tab bar unhidden, review screen text overlap fixed, glossary wording (item 8) applied except `fd_cfo`, duplicate Decided by you items merged to 8.
- `handoff.md`: wireframe review and sign-off section records the 2026-11-01 approvals and the pending wireframe work.
- Wireframe: the Score, Indices and Sector filter labels show the glossary tip on the label text (decision 16). Prose now says '200-day moving average (200 DMA)' and 'last twelve months' instead of EMA and TTM outside the glossary (decision 10). The review screen shows all 17 decisions and 5 proposals as approved.
- Wireframe: decision 10 reversed on 2026-11-01. The 200-day average is simple (200 DMA); the 50-day stays exponential (50 EMA). The technical vote list counts EMAs 10, 20, 50 and 100 only.
- Wireframe: all static (i) buttons converted to dotted-underline label tips. Only the three sort-header tips (verdict, score, run), built at runtime, still use the (i) button.
- Wireframe: the five review-page sections (Design decisions for approval, Decided by you, Calculator function contract, UI implementation notes, Proposals for approval) removed from `#/review`. Full text kept in `docs/wireframe-review-2026-11-01.md`. The page now shows a "Review closed 1 Nov 2026" card plus Intentionally deferred, New glossary keys and the glossary table.
- Scanner wording says 200 DMA instead of 200 SMA in `scanner/report.py`, `workbook.py`, `revenue.py`, `portfolio.py`, `conclude.py` and `indicators.py`. No keys renamed (`sma200` and `above_sma200` stay). The conclusion number guard in `scanner/conclude.py` exempts "N DMA".
- Wireframe: event chips are R, D, S, B, F (filings typed with importance High, Medium or Low) and V. Corporate actions mode buttons are All, Dividend, Split, Bonus and Other, with Split and Bonus as separate buttons.

- `tests/test_ui_api.py` `UIApiContractTests`: with no completed run in Postgres, `setUpClass` sets `skip_reason` instead of raising `SkipTest`, and `setUp` skips each test. All tests now count as skipped in "Ran N", so N no longer varies with the data.
- `tests/test_ui_api.py`: `test_config_lists_all_five_sources` is now `test_config_lists_the_five_core_sources` and checks the five core sources are present, so extra sources in the live `collector_settings` table (index_eod, gov_feeds, exchange_results) no longer fail it.
- Wireframe, Events and filings chart: sample order filings reworded so each matches a different Order book keyword group (`Letter of award received, 412 cr`, `Bags order worth 248 cr`, `Work order received, 96 cr`). They are still classed as Order win, High.
- Wireframe, Order book: "Left out" also lists filings whose keyword group is switched off, marked "Filter off". The count, the Excluded LODR filings card and the live announcement include them. Orders and totals do not.
- Wireframe, Sector and industry performance (Industry tab): "All industries" ranked list, "Technical trends" cards for the top five and weakest five, and a minimum group size of 4 stocks for ranking and the bars. Glossary keys `ind_all`, `ind_trend` and `min_group`.
- Wireframe, stock chart: removed the duplicate 200 DMA line. It was the same 200-day average as the exit line, scaled by 1.01. The chart now draws one line, the Exit line, on by default, and the 200 DMA legend entry is gone.
- `tests/test_mongo.py` authenticates with `SCANNER_MONGO_*` from `.env`, so the Mongo tests run. New `scripts/grant_test_dbs.js`: one-time grant of the `scannerTestDbs` role to the app user for the test databases.
- `scripts/pull_upstox_5y.py` now stores a short, token-redacted error text (max 300 chars) in a new `pull_log.error` column, with an automatic `ALTER` for existing databases.
- `tests/test_mongo.py`: `MongoDBBackendTests` is skipped with a class decorator, so its tests count as skipped instead of vanishing from "Ran N".
