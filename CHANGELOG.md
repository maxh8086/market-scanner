- `scanner/home_events.py` `fetch_feed` (home filings, T4b): fetches one NSE feed after a random 5 to 8 second gap, retries once after 30 seconds when the run deadline allows, and returns ok, blocked, transient or fatal. 10 offline tests in `tests/test_home_events_run.py`.
- `server/src/homeEventsRoute.ts` and `server/src/homeEventsAuth.ts` (home filings T5b): `POST /internal/events/batch` ingests `home_events` rows. An oversize batch returns 413 before auth. The bearer token for the `home_events_ingest` role is checked (401 if missing, 403 if wrong). Invalid rows are counted and skipped. The route is registered only when `checkToken` and `eventsTx` are passed to `buildApp`. 4 vitest tests in `server/src/homeEventsRoute.test.ts`.
- `scanner/home_events.py` `run_cycle` (home filings T4c): runs one cycle over the enabled NSE feeds, starting from a rotation index that changes every 300 seconds, skips an exchange while its cooldown is active, and starts a feed only if the run deadline allows it. Invalid rows end the run as `failed`. Repeated keys in one batch are posted once. Invalid run parameters raise `config:<key>`, including values too large for the datetime range (for example `run_deadline_s` of 10**12). 40 offline tests in `tests/test_home_events_run.py`.
- `scanner/home_events.py` `post_events` (home filings T6): posts rows to `POST /internal/events/batch` in batches of 500 with a bearer token and returns the summed inserted, duplicates and invalid counts. A non-2xx response raises RuntimeError without the token.

### Changed
- 2026-11-02: Phone (375px) header gap tightened to 8px so the stock page no longer scrolls sideways (document width 385px -> 375px). Tooltip check at 375px re-run: 251 triggers, 0 failures.
- Glossary wording for the all-time high now matches the scan: it uses the daily high (`scanner/ath.py` `compute_ath`) and a percentage clamped at 0. The 2% rule was replaced with the 0-5% bucket (`crit_ath`, "Price within 5% of all-time high"). The wireframe glossary is generated from `config/glossary.json` by `scripts/build_wireframe_glossary.py` (marker block in `ui/wireframes/strategy.html`), and `tests/test_glossary.py` fails if it is stale.
- Stale constituent ISINs are corrected automatically. `ath_scan.py` and `scripts/pull_upstox_5y.py` resolve each (symbol, ISIN) against the Upstox NSE master via `scanner/isin_resolver.py` and print one line per changed ISIN or rename; storage stays keyed by symbol. On Postgres, `ath_scan.py` records `isin_history` and `symbol_alias` (failures only warn). If the master is unavailable, the CSV ISINs are used with one warning. On an HTTP 400, the puller re-resolves from a fresh master and retries once, only when the ISIN changed. Tests in `tests/test_isin_wiring.py`.
- The NSE factor cache (`fetch_metadata`, `announcements`, `corporate_actions`) and `intensity.load_announcements()` now use Postgres when `MARKETDATA_BACKEND` is postgres (the default), so `data/factors.db` is never opened. The SQLite code runs only under `MARKETDATA_BACKEND=sqlite`. Migration `011_fetch_metadata_pull_log.sql` adds `fetch_metadata` and `upstox_pull_log`. Fixed in the Postgres writers and readers: `desc` is quoted in SQL, and rows with no parsable date are skipped instead of sending blank text to date columns. Tests in `tests/test_factors_backend.py`.
- `ath_scan.py` fails fast when Postgres is down or unconfigured: a `SELECT 1` check runs before the symbol loop, and an infrastructure error during a history fetch (`psycopg.OperationalError`, or a config RuntimeError from `scanner/pg/db.py` or `scanner/mongo.py`) aborts the run. Both print one stderr line and exit 3, with no rows written to `logs/skipped.csv`. Other per-symbol errors still skip only that symbol. Tests in `tests/test_ath_scan_backend.py`.
- Unconfigured backends fail with a clear message: Mongo selected with no `SCANNER_MONGO_USER` or `SCANNER_MONGO_PASSWORD` (`scanner/mongo.py`) and Postgres with no `POSTGRES_*` (`scanner/pg/db.py`) now name the variables and the offline escape (`DOCSTORE_BACKEND=tinydb`, `MARKETDATA_BACKEND=sqlite`). Tests in `tests/test_backend_defaults.py` and `tests/test_pg_dsn.py`.
- Backend defaults: `MARKETDATA_BACKEND` unset means `postgres` and `DOCSTORE_BACKEND` unset means `mongo`. `sqlite` and `tinydb` are used only when set explicitly. The auto-detect and the silent fallback to local files are removed, and invalid values raise `ValueError`. `scanner/factors.py` uses `get_backend()`. Tests in `tests/test_backend_defaults.py`.
- `tests/test_import_sqlite.py`: the reachability probe (`SELECT 1`) moved to module level, and the class is skipped with `@unittest.skipUnless` when Postgres is unreachable. The unguarded `setUpClass` connect no longer errors, and the class counts as skipped. It is also skipped when `data/history.db` is missing, so the tests are no longer errors in a checkout without that file.
- `scanner/pg/db.py` `dsn()`: raises RuntimeError when `POSTGRES_DSN` user or database differs from `POSTGRES_USER` or `POSTGRES_DB` (names only, no password or host). Tests in `tests/test_pg_dsn.py`.
